# Security Policy

## Supported versions

Security fixes are applied to the latest released version of tsdevstack.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting (the "Report a vulnerability" button in the Security tab), or email hello@tsdevstack.dev.

Include the affected version, a description of the issue, and steps to reproduce if you have them.

You can expect an initial response within 72 hours. Once a fix is released, we are happy to credit reporters who want acknowledgement.
